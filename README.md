# MAWO — My Adaptive Wellness Organizer

> Your Habits, Alive. A habit tracker built on neuroscience.

MAWO is a free, open-source Android habit tracker designed around the science of behavior change. It adapts to how you actually live — not how you wish you did.

## Features

- **Adaptive habit tracking** — built on the MAWO framework (neuroscience-based habit formation)
- **Smart notifications** — reminders that work with your schedule
- **Import / Export** — your data stays yours, always
- **Day selection** — track habits on specific days of the week
- **Fully offline** — no internet required, no accounts, no tracking
- **No ads, no analytics, no Firebase**
